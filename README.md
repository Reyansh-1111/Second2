🚀 CHITCHAT & TRIVIA BOT!

Instead of making a boring, dry command-line script, I wanted to give my bot a massive dramatic personality. It gets excited, it gets completely EXHAUSTED out of nowhere, and it demands to play games with you when it gets bored.

🎮 What it does:
1. Dynamic Chatting: Asks for your name and age, validating answers dynamically so it doesn't break if you mistype.
2. Would You Rather: Puts you on the spot with classic superpower dilemmas.
3. Rapid-Fire Trivia: A 6-question quiz checking geography, math, and space while tracking your score live.

🛠️ How I built it:
- Written entirely in pure Python.
- Leveraged strict logic matrices and input sanitation (.strip().lower() methods) to build robust recursive option check loops.
- Used custom timed dialogue pauses to make the text delivery feel human and conversational.
